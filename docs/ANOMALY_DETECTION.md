# Multi-Method Fire Activity Anomaly Detection

## 1. Overview & Operational Goal
Detecting genuine fire activity anomalies requires distinguishing normal harvest surges from truly unusual events (unseasonal burning, extreme single-cell flares, prolonged multi-day elevations, or localized cluster outbreaks).

The Statistical Anomaly Detector (`backend/services/anomaly/detector.py`) combines four complementary methodologies:
1. **Parametric Z-Score ($Z$)**: Measures deviation in units of standard deviations.
2. **Robust Median Absolute Deviation (MAD Score)**: Scale-invariant deviation resistant to extreme masking outliers.
3. **Exponentially Weighted Moving Average (EWMA)**: Tracks recent temporal momentum ($\alpha = 0.3$).
4. **Spatial Cluster Co-occurrence**: Evaluates neighboring grid cell fire density within a $25\text{ km}$ geodesic radius.

---

## 2. Statistical Formulations

### 2.1 Z-Score Deviation
$$Z = \frac{x_t - \mu_{\text{baseline}}}{\sigma_{\text{baseline}}}$$

Flagged as parametric anomaly when $Z \ge 2.5$ ($\alpha \approx 0.012$ under normality).

### 2.2 Robust MAD Score
$$\text{MAD Score} = \frac{x_t - \text{Median}_{\text{baseline}}}{\text{MAD}_{\text{baseline}}}$$

Flagged as robust anomaly when $\text{MAD Score} \ge 3.0$.

### 2.3 EWMA Momentum Tracking
$$S_t = \alpha x_t + (1 - \alpha) S_{t-1}, \quad \alpha = 0.3$$
$$\text{EWMA Score} = \frac{x_t - S_t}{\sigma_{\text{baseline}}}$$

## 3. Typology & Severity Classification

### Anomaly Typology
- `SPIKE`: High single-day deviation exceeding both MAD and Z-score thresholds within normal seasonal windows.
- `UNSEASONAL_TIMING`: Substantial burning observed outside traditional Kharif/Rabi harvest windows (e.g. July or January).
- `SPATIAL_CLUSTER`: High co-occurrence count of active fire cells within $25\text{ km}$ radius.
- `PROLONGED_ELEVATION`: Multiple consecutive days of persistent elevation above baseline.

### Severity Tiers
| Tier | Criteria | Operational Action |
| :--- | :--- | :--- |
| `CRITICAL` | $\text{MAD} \ge 4.5$ or ($Z \ge 4.0$ and $\text{FRP} \ge 50\text{ MW}$) | Immediate alert to district environmental authorities & mobile bio-refinery dispatch. |
| `HIGH` | $\text{MAD} \ge 3.0$ or $Z \ge 2.5$ | Warning flag for regional monitoring. |
| `MODERATE` | $\text{MAD} \ge 2.0$ or $Z \ge 2.0$ | Advisory notification. |
| `LOW` | Spatial/Unseasonal deviation below high threshold | Logged for statistical trend analysis. |

---

## 4. Transparent Diagnostic Explainability
Every flagged anomaly is paired with structured human-readable JSON diagnostics generated by `AnomalyExplanationService`:
- Exact observed value vs expected baseline median.
- Percentage increase above norm ($+X\%$).
- Parametric ($Z$) and non-parametric ($\text{MAD}$) deviations.
- Spatial cluster context (isolated vs part of multi-cell outbreak).
- Data sufficiency statement certifying observational confidence.
